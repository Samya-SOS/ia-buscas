Modificações Implementadas:

    1. Implementação da Busca em Profundidade Limitada Iterativa para resolver o problema do 8-puzzle.
    2. A busca começa com profundidade aumenta iterativamente a partir de 0 até encontrar a solução ou atingir o limite máximo de profundidade.
    3. A lógica de profundidade limitada foi alterada para permitir a execução progressiva com profundidade crescente, evitando o estouro de memória.
    4. O código foi modificado para usar a classe BuscaEmProfundidadeLimitadaIterativa no lugar da busca em profundidade tradicional.
